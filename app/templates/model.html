Como treinar

Esta tela é somente leitura: as métricas são lidas de data/models/metrics.json, produzido por train/train.py — nada é calculado aqui. 

pip install -r train/requirements.txt
python3 train/train.py \
  --data datasets/v1/data.yaml \
  --epochs 100

Ao terminar, o script copia best.pt para data/models/ e a aplicação detecta os pesos novos sozinha, pelo mtime, sem reiniciar. O ciclo completo está em train/README.md.
